# 🐍 Snake Water Gun Game in C

A simple console-based game where the player competes against the computer using Snake, Water, or Gun.

### Features

* Player vs Computer
* Random computer choice
* Winner detection
* Draw handling

### Concepts Used

* `if-else`
* `switch`
* Random numbers
* Loops and variables
* User input/output

A beginner-friendly project to practice decision-making and randomization in C.
